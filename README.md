## CRUD-операции

Наша СУБД поддерживает полный цикл работы с записями в таблицах (создание, чтение, обновление, удаление). Данные каждой таблицы изолированно хранятся в формате JSON в директории `data/`.

### Системные требования к данным
*   **Автоматический ID:** При добавлении записи (`insert`) указывать значение ID не нужно. СУБД автоматически генерирует уникальный ID на основе максимального существующего идентификатора в таблице (метод `max(IDs) + 1`).
*   **Обязательность полей:** Все объявленные при создании таблицы столбцы являются строго обязательными для заполнения.
*   **Строковые значения:** Все строки (тип `str`) в условиях фильтрации `WHERE` и `SET` обязательно должны быть обёрнуты в кавычки (например, `"Ivan"` или `'Alex'`).

---

### Описание команд и синтаксис

1.  **`insert <имя_таблицы> <значение1> <значение2> ...`**
    Добавляет новую строку в таблицу. Значения передаются через пробел в порядке объявления столбцов (исключая ID).
    *Пример:* `insert users "Ivan" 25 True`

2.  **`select <имя_таблицы> [условие]`**
    Выводит содержимое таблицы в красивом табличном формате с помощью библиотеки `PrettyTable`. Если условие не указано, выводит все записи.
    *Пример:* `select users` или `select users age = 25`

3.  **`update <имя_таблицы> set <поле = значение> where <поле = значение>`**
    Обновляет указанные поля в записях, соответствующих критерию фильтрации.
    *Пример:* `update users set is_active = False where age = 25`

4.  **`delete <имя_таблицы> where <поле = значение>`**
    Удаляет из таблицы записи, которые подходят под условия фильтра.
    *Пример:* `delete users where age = 25`
