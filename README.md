## Управление таблицами

В нашей примитивной СУБД реализовано интерактивное управление структурой базы данных через консольный интерфейс. Все изменения автоматически валидируются и сохраняются в файл метаданных `metadata.json`.

### Доступные команды

*   **`create_table <имя_таблицы> <имя_столбца1:тип> <имя_столбца2:тип> ...`**
    Создает новую таблицу с указанными столбцами. 
    *   *Особенности:* Автоматически добавляет первичный ключ `id` с типом `int` в начало таблицы. Выдает ошибку, если таблица уже существует или передан неподдерживаемый тип данных.
    *   *Допустимые типы данных:* `int`, `str`, `bool`.
*   **`drop_table <имя_таблицы>`**
    Полностью удаляет указанную таблицу и все её данные из системы. Выдает ошибку, если таблица не найдена.
*   **`help`**
    Выводит краткую справочную информацию по доступным командам.
*   **`exit`**
    Безопасно завершает работу программы.

### Пример использования

После запуска проекта с помощью команды `uv run project` вы увидите интерактивную строку ввода `>`. 

**1. Создание таблицы:**
```bash
> create_table users name:str age:int is_active:bool
Успех: Таблица 'users' успешно создана.
```

**Результат в `metadata.json`:**
```json
{
    "users": {
        "columns": {
            "id": "int",
            "name": "str",
            "age": "int",
            "is_active": "bool"
        },
        "rows": []
    }
}
```

**2. Попытка создания дубликата или неверного типа:**
```bash
> create_table users name:str
Ошибка: Таблица 'users' уже существует.

> create_table products price:float
Ошибка: Недопустимый тип данных 'float' для столбца 'price'.
Разрешенные типы: int, str, bool.
```

**3. Удаление таблицы:**
```bash
> drop_table users
Успех: Таблица 'users' успешно удалена.
```
